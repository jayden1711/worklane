### Upgrading (from v0.5.2)

- **A server's first hour (#739, part 2 of 2): the hardened bootstrap points at Add project for the instance's credentials.** Its first run no longer ends with "next, by hand" (an App made by hand with `credentials.sh <name> github-app`, a `claude setup-token` token, then `--after-credentials`). It names Add project instead: in the dashboard's Setup console once you are signed in, or the same steps at a root shell, `sudo bash scripts/setup/add-project.sh <name> <owner/repo>`. Add project makes the agents' App through GitHub's manifest flow and waits for the agents' Claude login. The quickstart says the same. An install whose credentials were stored by hand keeps them, and `--after-credentials` still finishes it, unchanged.
