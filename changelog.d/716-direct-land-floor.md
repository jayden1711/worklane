### Guardrail changes: what each one does

- **Direct land holds the categories PR mode always holds for a human (#716).** `land_mode: direct` skips the merge decision. So a change in a category PR mode always holds for a human (review.yaml's L3 categories, CI config, the agents' own instructions, the harness's own controls, the odd paths, the repo's `merge.wait_categories`, and dependency manifests) could land at L0 to L2 with only the evaluator's approval. Such a change is now raised to L3, and the owner is asked, with the same reasons the merge policy gives in PR mode. The rest of the merge decision still doesn't apply to a direct land: the evaluator's binding design flag, a new top-level module, a claimed protected path (`claimedProtected`), the weakening and vacuity holds (#783, #784), the size limits and its other doubt reasons.
