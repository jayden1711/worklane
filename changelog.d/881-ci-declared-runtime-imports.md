### Guardrail changes: what each one does

- **Test selection follows a declared runtime import, and tsconfig's own build list (#881).** A computed `import()` or `require()` of an installed path can name the repo file it loads, in a comment on the line right above it: `// runtime-import: src/x/index.ts`. That file then counts as an import, so a change to it selects every test that reaches the module. The comment counts only if the file exists and the code around the import names that file's built path. Otherwise the test still runs on every change. The engine's CI now maps built paths back to their sources from `tsconfig.json`'s `include` (each `<dir>/**/*.ts`), so `scripts/bench/` resolves like `src/` and `test/`. The root updater declares its watchdog import (a comment, no behaviour change).
