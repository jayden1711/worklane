### Upgrading (from v0.5.2)

- **The optional desktop window is removed (#744, #746).** Open the dashboard in your browser instead: the same page, sign-in and guards. `dashboard --app` now opens the browser, as it already did when the window wasn't built. Removals lists what went.
- **The `desktop` check stays for one more release, as a CI job that only succeeds (#746).** Every install so far has `desktop` in `/etc/worklane/updates.json` `required_checks`, and an updater from v0.5.2 or older waits for a successful `desktop` run on every commit it installs, on the release channel too (it reads the checks on the release's base commit). So the job keeps its name and still runs on every pull request and every push to main, and a v0.5.2 install updates to this release as usual. The `desktop` entry also stays in the engine repo's required checks and in a new install's default `required_checks`. The release after this one removes the job and the check together (#877), and its notes say so.
- **v0.5.2 installs: rerun `updates.sh` once, as root, after upgrading to this release:** `sudo bash /opt/worklane/current/scripts/setup/updates.sh`. It is the same rerun After install asks for (#755, #761), so one rerun covers all three. It installs this release's updater, which no longer waits for the retired `desktop` check when a commit has no run of it, and keeps `updates.json` as it is (on or off, channel and checks included). Without it, the machine stops installing updates once the release after this one removes the job (fail-closed, nothing opens), and the journal says why: `required check "desktop" hasn't run on this commit`.

### Removals

- **The desktop window (#744, #746):** `desktop/` (the Tauri shell, 74 lines of Rust, and its 4,466-line `Cargo.lock`), `npm run build:desktop`, the `dashboard --app` window and `src/desktop.ts`, with its entry in `THIRD_PARTY_NOTICES.md` and the denylist's skip for its lockfile. Replacement: the dashboard in a browser. The updater never built or installed the window, so no install had it unless someone built it by hand. Its CI job no longer builds or tests anything: it only succeeds, for one more release (see Upgrading).
