### Upgrading (from v0.5.2)

- **The dashboard shows every changed path the way the engine's reasons do (#768).** A file chip, a decision's file list, the files the evaluator didn't read, a finding's file, the impact flags, a PR's conflict-fix files and light-check overlap, a hold's files, the health panel's hotspot file, a run's written files, an experiment's changed files and a live diff's file now go through the engine's own path display (`shownPath`): a name with a bidi override, a zero-width, a control or another invisible character (or one #763 escapes) shows escaped (`\uXXXX`, JSON-quoted), so it can't reorder or hide the text around it. Plain names show as before. The data the API serves stays raw. A decision's impact flags, read from the issue's log, list such a file again: its level reason names it escaped, and it is now matched as shown.
