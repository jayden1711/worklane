### Guardrail changes: what each one does

- **One shared list of token shapes (#889).** The engine's redactor (`src/events/redact.ts`) now knows a Discord bot token and a Tailscale key. Each was redacted only by one module of its own before (the watchdog's incidents, the Tailscale step lines), so a Discord bot token passed through to the event log, issue comments, chat notices and the dashboard's service log. The dashboard's service-log file is redacted as one text before it is split, so a private key over several lines is masked whole. A Tailscale key in a Tailscale step line now shows as `tskey-[REDACTED]` (was `[a key]`). A bare 32-character key with no prefix stays unmasked when it stands alone: a commit hash or an id looks the same. A test fails on any module that redacts a token shape with its own pattern.
