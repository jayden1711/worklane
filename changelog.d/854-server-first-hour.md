### Upgrading (from v0.5.2)

- **A server's first hour (#739, part 1 of 2).** The First run page's server checklist gains **Your first task** after the coordinator: done once the coordinator has taken a writer's `ready` issue with a `done_when` block, as it judged it (`issue.seen` in the instance's event log); the App's own issues never count. The **Engine updates** step moves after it and, until the instance opens its first PR (or lands a change directly), is listed but blocks nothing: shown as optional, with why. From the first PR on, or whenever the event log can't be read, it is required as before; `doctor` lists it either way. Nothing about an installed updater changes: its files, signers and channel are only read. With no https origin yet, setup mode and the install command offer the origin as a choice: one of your own (`--public-url https://<host>`), or Tailscale (screen 7).
